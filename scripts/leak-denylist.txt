# leak-denylist.txt -- patterns that must never appear anywhere in this public tree.
#
# One pattern per line. '#' starts a comment, blank lines are ignored.
#   plain text     -> case-insensitive substring match
#   re:<regex>     -> case-sensitive Python regex
#   rei:<regex>    -> case-insensitive Python regex
#
# scripts/leak-gate.py scans every text file line by line AND every member of zip-based
# archives (.zip .xlsx .docx .pptx .odt .jar ...) at raw level, because vendor and client
# references have hidden inside xl/comments/*.xml and docProps/*.xml where a cell-value
# scan never looks. Legitimate matches go in an allow file (--allow, one `path:pattern`
# per line); the list itself is never loosened to make a scan pass.
#
# THIS SHIPPED LIST IS DELIBERATELY GENERIC. A denylist that names the people, clients,
# hosts and key aliases it protects would publish exactly what it is meant to hide. Keep
# the identity-bearing list in your PRIVATE tree and layer it on at scan time:
#   python scripts/leak-gate.py . --denylist scripts/leak-denylist.txt --denylist ../private/leak-denylist.private.txt
# Real money figures (budgets, spend, envelopes) are likewise NOT listed; the regex at the
# bottom flags every 3+ digit dollar amount for a human look instead.

## Domain words, private key-file names and virtual-key env-var schemas are NOT listed
## here on purpose: a shipped list that named them would publish what it protects, and
## the gate skips its own pattern file so it could never catch that. Put yours in the
## private list layered on at scan time (see above). Dangerous FILE NAMES need no
## pattern at all - the gate flags .env, .env.* (except .env.example),
## .virtual-keys.env, *.pem, *.key and id_rsa* by name.

## Network identity: tailnet (CGNAT 100.64/10), private LAN and docker-subnet addresses, mesh auth-key shape
re:\b100\.(6[4-9]|[7-9]\d|1[01]\d|12[0-7])\.\d{1,3}\.\d{1,3}\b
re:\b192\.168\.\d{1,3}\.\d{1,3}\b
re:\b10\.\d{1,3}\.\d{1,3}\.\d{1,3}\b
re:\b172\.(1[6-9]|2\d|3[01])\.\d{1,3}\.\d{1,3}\b
re:tskey-[A-Za-z0-9-]+

## Personal paths and mailboxes
re:[A-Za-z]:[\/]Users[\/][A-Za-z0-9._-]+
rei:[a-z0-9._%+-]+@(?!example\.com)[a-z0-9.-]+\.[a-z]{2,}

## Secret shapes
re:sk-[A-Za-z0-9_-]{8,}
re:glsa_[A-Za-z0-9_]+
re:ghp_[A-Za-z0-9]{20,}
re:github_pat_[A-Za-z0-9_]{20,}
re:xox[abp]-[A-Za-z0-9-]+
re:AKIA[0-9A-Z]{16}
re:-----BEGIN [A-Z ]*PRIVATE KEY-----
re:tkn_[A-Za-z0-9_-]{8,}
re:Bearer\s+[A-Za-z0-9_\-]{24,}

## Money: any dollar amount of three or more digits (or with thousands separators) is
## flagged so a copied budget, cap or spend figure gets a human look before it ships.
re:\$\s?\d{1,3}(?:,\d{3})+(?:\.\d+)?|\$\s?\d{3,}(?:\.\d+)?
